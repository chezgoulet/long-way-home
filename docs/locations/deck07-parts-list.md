# Deck 7 — Auxiliary Computer Core, Cargo and Labs: parts list

The brief's section 4 leaves the parts list open, "to be completed from the pak census (computer core,
cargo crates, escape pod hatch)". This is that list. It is a census of the reuse source (`tour/deck11`,
the published deck the brief names), taken by `tools/shipmap/dressdeck07.py --census`, plus the pieces
this re-dress adds on top of it, each checked against the shipped game.

Deck 7 copies the **same room** decks 12, 13 and 14 copied (`tour/deck11`, main engineering), so the
source census is the same 77 materials and 4 models. The **difference is what this re-dress adds**.

| model | placed by this deck | where it comes from |
|---|---|---|
| `models/mapobjects/cargo/crate.md3` | 8 (two islands of four, to the sides) | shipped paks (`models/mapobjects/cargo/`), the brief's section 4 |

The crate's `mins`/`maxs` (`-24 -24 -16` / `24 24 16`) are the shipped cargo decks' own placements, so
the collision box matches the model. No new models: every model named here exists in the shipped game.

The **escape-pod hatch** the brief asks for has **no model in the game** (no escape-pod asset ships),
so it is authored geometry: a recessed ceiling hatch in `cargo/cargodoor1` with a lit
`engineering/elight1` rim, over a short walkable platform. Invented, and logged as such in
`docs/lore-ledger.md`. The **core column** is brushes too, from the room's own core materials (the
ones the dropped warp core used) — the same choice deck 13's machinery island made.

## The check

Every face texture used by the generated `deck07.map` resolves: an image in the paks, a shader the
game or our own data declares, one of the generated detail aliases, or a material in `tour/deck11`.

```
$ python3 tools/shipmap/parts_census.py --map build/ship/generated/deck07.map --game build/baseEF \
      --census build/ship/deck07-census.json --shader build/ship/files/scripts/lwh_detail07.shader
build/ship/generated/deck07.map: 86 distinct materials
  present as shipped images:      2694
  declared by shipped shaders:   2070
  our own aliases:               122
  in the reuse source census:    77
PASS  every material already exists in the game; no new art
```

The build runs this check, so a deck 7 that named art the game does not have would fail the build.
**No new art.** The command and its verdict are also in `docs/evidence/deck07-auxcore.md`.
